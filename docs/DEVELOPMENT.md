# Разработка

| Путь | Назначение |
| --- | --- |
| `web_app.py`, `start_panel.ps1` | Запуск локального сервера |
| `control_panel/server.py` | FastAPI, API и защита команд |
| `control_panel/engine.py` | Камера, инференс, телеметрия и цикл управления |
| `control_panel/tracking.py` | Ассоциация целей и расчёт скорости |
| `control_panel/sbgc.py` | Serial API SimpleBGC |
| `control_panel/static/` | Веб-интерфейс и преобразование координат |
| `detect.py`, `detection_filter.py` | Отдельный детектор и фильтр областей |
| `download_dataset.py`, `prepare_dataset.py`, `train.py` | Базовый цикл обучения |
| `adapt_*.py` | Эксперименты адаптации на локальных кадрах |
| `tests/` | Проверки без настоящих моторов |

## Диагностические скрипты

`inspect_controller.py` и `disable_frame_imu.py` сохранены как исходный код диагностики
конкретной платы COM9 / 2.70b0. Это не шаги установки приложения.
Им нужны локальные заголовки официального BaseCam Serial API в `research/basecam/`;
скрипту изменения IMU также нужен исходный резервный снимок профилей из `diagnostics/`.
Эти файлы не входят в репозиторий. Не запускайте скрипт записи как универсальную настройку другого подвеса.

## Что исключено из Git

Окружение Python, кэши, логи, пользовательские видео/кадры, `diagnostics/`, датасеты,
промежуточные обучения, локальные настройки панели и сторонние заголовки.
Из весов включён только `models/balloon.pt`. Скрипты экспериментов сохранены,
но их локальные данные не предоставляются.

Зафиксированные зависимости находятся в `requirements.lock.txt`; прямые зависимости —
в `requirements.txt` и `requirements-web.txt`. Node.js нужен только для тестов JavaScript.
