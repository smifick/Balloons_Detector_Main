# Активная модель

Файл: `balloon.pt` (~6.2 MB), YOLOv8n, один класс `balloon`.

Происхождение: базовое обучение на Matterport Balloon Dataset, адаптация к кадрам USB-камеры,
затем дообучение с маленьким светло-зелёным шариком и смешивание весов best/last второго этапа
с коэффициентом 0.65 для last. Исходные изображения комнаты не распространяются.
Скрипт `adapt_small_balloon.py` сохраняет часть процесса подготовки и обучения;
полное воспроизведение активных весов требует локальных кадров и промежуточных запусков.

| Параметр | Значение |
| --- | --- |
| Размер инференса панели | 640 |
| Порог отображения | 0.35 |
| NMS IoU | 0.4 |
| Проверочная выборка | 13 изображений Matterport |
| mAP@50 | 0.821711 |
| mAP@50–95 | 0.671816 |

Проверочная выборка участвовала в выборе модели. Дополнительная разметка зелёного шарика
получена из одной сцены; аугментации не являются независимыми съёмками.
Нет независимой оценки точности по цветам, дистанциям или новым помещениям.
Ложные срабатывания и пропуски возможны. `model_report.json` относится к более ранней версии.
